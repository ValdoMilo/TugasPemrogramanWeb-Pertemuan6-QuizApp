# Interactive Quiz App - Tugas Pemrograman Web (Pertemuan 5)

Repository ini berisi *source code* untuk tugas mata kuliah Pemrograman Web pada pertemuan kelima. Proyek ini berfokus pada pembuatan **Aplikasi Kuis Interaktif (Quiz App)** berbasis web yang memanfaatkan JavaScript murni (Vanilla JS) untuk pengelolaan logika permainan, manipulasi DOM, dan sistem penilaian.

## 📝 Deskripsi Proyek

**Quiz App** adalah aplikasi kuis interaktif di mana pengguna dapat menjawab serangkaian pertanyaan pilihan ganda. Aplikasi ini memproses jawaban pengguna secara *real-time*, menghitung skor secara otomatis, serta menampilkan hasil akhir kuis setelah seluruh pertanyaan selesai dijawab.

Proyek ini dirancang untuk melatih pemahaman mengenai struktur data (array & object di JS), pengondisian (*conditional logic*), *event handling*, serta pembaruan elemen antarmuka (*DOM manipulation*) secara dinamis.

## ✨ Fitur Utama

* **Navigasi Pertanyaan Dinamis:** Menampilkan pertanyaan dan opsi jawaban satu per satu tanpa perlu *reload* halaman.
* **Sistem Penilaian Otomatis:** Menghitung total jawaban benar dan salah secara akurat di akhir kuis.
* **Umpan Balik Visual (Visual Feedback):** Memberikan penanda warna saat pengguna memilih jawaban (benar atau salah).
* **Layar Hasil Akhir (Result Screen):** Menyajikan skor akhir beserta pesan atau ringkasan evaluasi kuis.
* **Fitur Kuis Ulang (Restart Quiz):** Memungkinkan pengguna untuk mengulang kuis dari awal tanpa menyegarkan (*refresh*) browser.
* **Tampilan Responsif:** Antarmuka yang rapi dan nyaman diakses baik dari desktop maupun perangkat seluler.

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur utama antarmuka kuis dan kontainer elemen.
* **CSS3 / SCSS:** Pengaturan tata letak, warna, tombol, serta efek transisi interaktif.
* **JavaScript (ES6+):** Menangani logika kuis, array data pertanyaan, *event listener*, kalkulasi skor, serta manipulasi DOM.

## 🚀 Cara Menjalankan Proyek

1. *Clone* repositori ini ke komputer Anda:
   ```bash
   git clone https://github.com/ValdoMilo/TugasPemrogramanWeb-Pertemuan5-QuizApp-.git
   ```

2. Buka folder proyek menggunakan editor kode pilihan Anda (seperti **Visual Studio Code**).

3. Jalankan proyek dengan cara:
   * Menggunakan ekstensi **Live Server** di VS Code, atau
   * Membuka langsung file `index.html` di browser favorit Anda.

4. Pilih jawaban yang menurut Anda benar dan selesaikan kuis hingga halaman skor muncul!
